# BMZ AI Backend

Backend مستقل لتطبيق BMZ AI.

## المنافذ

- التطوير الافتراضي: **4000**
- لا يعتمد على مشروع `web` القديم.
- يمكن تغيير المنفذ عبر متغير البيئة `PORT`.

## API

### GET /health

فحص حالة الخدمة.

### POST /api/agent

يستقبل:

```json
{
  "message": "حلّل مشروعي"
}
```

ويرجع خطة منظمة. التنفيذ الحقيقي سيُربط لاحقًا بطبقات Planner وOrchestrator وSandbox وPermissions.

## المبدأ

الهاتف هو واجهة التحكم، والـ Backend هو عقل المنصة، والتنفيذ يتم داخل بيئة معزولة وبصلاحيات صريحة.
