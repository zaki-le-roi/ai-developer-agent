# BMZ AI Sandbox

هذه الطبقة مخصصة لتنفيذ المشاريع في بيئة معزولة.

المراحل المخططة:

1. إنشاء مساحة مشروع مؤقتة.
2. قراءة الملفات المسموح بها.
3. تنفيذ أوامر غير خطرة داخل العزل.
4. تشغيل الاختبارات.
5. التقاط الأخطاء.
6. إعادة المحاولة وفق خطة محددة.
7. إعادة النتيجة إلى Orchestrator.

لا يجب تنفيذ أوامر حقيقية حساسة أو تعديل نظام المضيف مباشرة من Agent.
